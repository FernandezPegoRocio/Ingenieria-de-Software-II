para ejecutarlo

Instalá **Node.js** (versión LTS) desde nodejs.org, si todavía no lo tenés. Abrí una consola nueva después de instalarlo.

abri la carpeta y escribi cmd
ejecuta:
npm install
npm run build
npm test
npm start

luego entrá a http://localhost:3000

 Para detener el servidor toca la tecla rol + c en la consola
